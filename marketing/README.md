# marketing/

Everything written for showing the game to people. Nothing in here ships with the game.

The game is an early build and the ask is feedback, not attention — that framing runs through all of
it. Two thrusters, no accelerator and no fire button are stated as decisions, never as open
questions.

## Order to use it

**1. Post today — no gate anywhere.**

- [`showhn.md`](showhn.md) — Show HN. No karma minimum. The rendering and the phone pairing are the
  hooks; leads with the technical detail because that's what that audience shows up for.
- [`itch-io.md`](itch-io.md) — the itch.io page: build zip, settings, description, tags and a first
  devlog. Do this one first if you only do one. It gives every later post a real link to point at.

**2. Reddit, once the account clears the gate.**

- [`reddit/KARMA.md`](reddit/KARMA.md) — **read this first.** The first attempt was blocked at ~1
  karma against a ~25 requirement. Your account age already passes; only comment karma is missing.
- [`reddit/PLAYBOOK.md`](reddit/PLAYBOOK.md) — order, timing, the first hour, what to reply to the
  predictable comments, and how to run the score challenge.
- [`reddit/subreddits.md`](reddit/subreddits.md) — 14 targets ranked by where you'll get a useful
  answer, with links to each one's rules. **The rules were not read live** — Reddit blocks the
  machine this was written on — so check each before posting.
- [`reddit/POST.md`](reddit/POST.md) — the canonical post, the follow-up comment and title options.
- [`reddit/variants/`](reddit/variants) — six paste-ready per-subreddit versions.
